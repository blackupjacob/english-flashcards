# 영어 플래시카드 (BLACKUP COFFEE · 로스터의 실전 영어)

스페셜티 커피 로스터리를 운영하는 **한국인 대표**의 1인칭 시점으로 쓴 영어 학습 앱입니다.  
해외 생두 수입사·농장과의 연락, 커핑 노트, 로스팅 프로파일, 카페 도매 거래처, 박람회, 고객 응대, 배송 지연, 이메일·회의는 물론 일상·여행·음식·감정·관용구·시사·격식 표현까지 담았습니다.  
**«멜버른 행사»** 주제에는 멜버른 커피 엑스포 부스 응대·스몰토크·네트워킹·카페 주문 문장과, 현지에서 자주 듣는 호주 구어(How ya going?, arvo, no worries, reckon, servo…) 이해용 카드가 있고, 참고 메모에 호주식 표현을 달아 두었습니다.

- **앞면**: 한국어 문장/뜻
- **뒷면**: 영어 세 가지 레지스터
  - **미국식 구어체** — gonna, check, takeout, pour-over, circle back 등
  - **격식체/문어체** — 비즈니스 이메일·공식 문서 톤
  - **영국식 구어체** — cheers, knackered, bill, takeaway, give it a go 등

공개 페이지: https://blackupjacob.github.io/english-flashcards/

## 발음 듣기 (TTS)

브라우저 내장 **Web Speech API**(`speechSynthesis`)로 읽어 줍니다. 서버·API 키 없음.

- 카드를 뒤집으면 각 영어 블록에 🔊 버튼: 미국식 구어체·격식체 → **en-US**, 영국식 구어체 → **en-GB**
- «멜버른 행사» 카드에는 🇦🇺 **호주 발음**(en-AU) 버튼이 추가됩니다. (참고 메모는 읽지 않음)
- 로케일별로 가장 좋은 음성을 자동 선택(Enhanced/Premium/Natural·Google·Siri 우선, 장난감 음성 제외). 없으면 가장 가까운 영어 음성으로 읽고 안내가 뜹니다.
  - iPhone·iPad: 설정 > 손쉬운 사용 > 읽기 및 말하기 > 음성 > 영어 에서 영국/호주 음성(향상된 음성) 다운로드
- «발음 듣기» 패널: 읽기 속도 **보통 / 천천히**, **뒤집으면 자동 재생**(기본 끔 · 혼합 모드는 목표 레지스터, 기본은 미국식 구어체). 설정은 `english-flashcards-tts-v1`에 저장.
- 재생 중 버튼을 다시 누르면 정지, 다른 버튼을 누르면 이전 음성을 끊고 새로 읽습니다.

## 오늘의 세트 · 주간 복습

- **오늘 세트**: 필터된 덱에서 **로컬 날짜 시드**로 섞어 하루치 카드를 뽑습니다. 같은 날·같은 필터면 같은 순서, 다음 날이면 다른 구성입니다. UI에 오늘 날짜와 «오늘의 세트»가 표시됩니다.
- **하루 목표**: 기본 **18장** (12 / 15 / 18 / 20 / 25 선택 가능).
- **주간 복습**: 맞혀도 롤링 **7일** 안에 대략 **2번** 다시 나옵니다.
  - 첫 맞음 → 주 안에 한 번 더 복습 일정
  - 틀림 → 같은 세션 큐에 약 3장 뒤 재삽입 + 주간 노출에도 포함
- 스케줄은 브라우저 `localStorage`에 카드 id별로 저장됩니다. (키 접두사 `english-flashcards-` — 스페인어 앱과 겹치지 않음)

## 주간 레벨 보고 (CEFR 추정)

학습 기록(맞음·틀림, 난이도, 주제)을 `localStorage`에 쌓아 **달력 주(월–일)** 기준으로 추정 레벨을 보여 줍니다.

- UI: 접이식 패널 **«주간 레벨 보고»** (오늘의 세트 바로 아래)
- 표시: 추정 레벨(A1–C2), 근거(정답률·주로 푼 난이도), 학습 장수·정답률·난이도/주제 구성, 지난 주 추정(최대 8주)
- **보고서 복사** 버튼으로 한국어 요약을 클립보드에 복사
- **추정 · 학습 기록 기반**이며 공식 등급이 아닙니다. 공인 레벨은 IELTS·TOEFL·Cambridge 등 공인 시험이 필요합니다.

### 레벨 추정 방식 (휴리스틱)

1. 난이도 대역 → 기본 점수: 아주쉬움≈A2–B1(1.5), 쉬움≈B1(2), 어려움≈B2(3), 아주어려움≈C1(4)
2. 이번 주 정답률로 가감: 어려운 카드 고정확 → 상향, 쉬운 카드 저정확 → 하향
3. 학습량이 적으면 높은 등급을 과신하지 않도록 보정

## 사용 방법

1. **주제**를 고릅니다. (일상, 직장·비즈니스, 커피·카페, 여행, 음식, 감정, 문화, 시사, 관용구, 격식, 멜버른 행사 — 여러 개 선택 가능)  
   전체가 선택된 상태에서 하나를 누르면 그 주제만 선택됩니다. «전체»로 다시 모두 선택.
2. **난이도**를 고릅니다. (`전체` / `아주쉬움` / `쉬움` / `어려움` / `아주어려움`)
3. **학습 모드**
   - **기본 학습**: 한국어 → 영어(미국식 구어체 기준). 뒷면에 세 레지스터 모두 표시.
   - **혼합 재학습**: 앞면은 여전히 한국어. 카드마다 **미국식 구어체 / 격식체·문어체 / 영국식 구어체** 중 하나를 목표로 지정합니다.
4. **내 CSV 덱** (선택): 직접 만든 문장 CSV를 올려 공부할 수 있습니다.
5. «학습 시작»(진행 중에는 «다시 시작»)을 누르고, 카드를 **탭**해 뒤집으면 영어 답이 나옵니다. **맞음 / 틀림** 버튼은 뒤집힌 뒤에만 보입니다.
6. 답 화면에서 그 문장의 난이도를 바꿀 수 있습니다. 변경은 `localStorage`에 저장됩니다.

키보드: Space/Enter 뒤집기 · 1/← 틀림 · 2/→ 맞음

## CSV로 카드 추가

1. [sample-cards.csv](sample-cards.csv)를 받아 열을 맞춥니다. (Excel은 **UTF-8 CSV**로 저장)
2. 앱에서 파일을 선택합니다.
3. 덱 출처: **기본 덱** / **CSV만** / **합치기**

### 열 (헤더)

| 열 이름 | 설명 |
|---------|------|
| `front_ko` | 앞면 한국어 문장 (필수) |
| `casual_us` | 미국식 구어체 (필수) |
| `formal_en` | 격식체/문어체 (필수) |
| `casual_uk` | 영국식 구어체 (필수) |
| `difficulty` | `아주쉬움` \| `쉬움` \| `어려움` \| `아주어려움` |
| `topics` | 주제 id. `\|` 또는 `;`로 여러 개 (예: `커피\|직장`) |
| `notes` | 선택 메모 |

주제 id: `일상`, `직장`(직장·비즈니스), `커피`(커피·카페), `여행`, `음식`, `감정`, `문화`, `시사`, `관용구`, `격식`, `멜버른`(멜버른 행사). 다른 값을 쓰면 새 주제 칩이 생깁니다.
