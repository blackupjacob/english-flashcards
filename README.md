# 영어 플래시카드 (BLACKUP COFFEE · 로스터의 실전 영어)

스페셜티 커피 로스터리를 운영하는 **한국인 대표**의 1인칭 시점으로 쓴 영어 학습 앱입니다.  
해외 생두 수입사·농장과의 연락, 커핑 노트, 로스팅 프로파일, 카페 도매 거래처, 박람회, 고객 응대, 배송 지연, 이메일·회의는 물론 일상·여행·음식·감정·관용구·시사·격식 표현까지 담았습니다.  
**«멜버른 행사»** 주제에는 멜버른 커피 엑스포 부스 응대·스몰토크·네트워킹·카페 주문 문장과, 현지에서 자주 듣는 호주 구어(How ya going?, arvo, no worries, reckon, servo…) 이해용 카드가 있고, 참고 메모에 호주식 표현을 달아 두었습니다.

- **앞면**: 한국어 문장/뜻
- **뒷면**: 영어 세 가지 레지스터
  - **미국식 구어체** — gonna, check, takeout, pour-over, circle back 등
  - **격식체/문어체** — 비즈니스 이메일·공식 문서 톤
  - **영국식 구어체** — cheers, knackered, bill, takeaway, give it a go 등

공개 페이지: https://blackupjacob.github.io/english-flashcards/

## 발음 듣기 · 발음 연습

발음이 아쉽다는 피드백에 따라 **고품질 녹음 음성**을 기본으로 바꿨습니다. 기기 음성(Web Speech API)은 예비/대체로 계속 쓰입니다. 서버·API 키 없음(정적 파일).

### 소리 (🔊)

- 기본: `audio/*.mp3` — **Kokoro-82M v1.0**(Apache-2.0)으로 미리 만들어 둔 파일. 미국식 구어체·격식체 = **af_heart**(미국 여성), 영국식 구어체 = **bf_emma**(영국 여성). 문장마다 «보통»·«천천히»(0.8배속) 두 벌, 총 966개(약 24MB, 40kbps mono mp3). 음량은 ffmpeg `loudnorm`으로 -18 LUFS에 맞춤.
- **내 CSV로 추가한 카드**나 파일이 없는 경우, 파일이 없다/네트워크 오류가 나는 경우 → 자동으로 **기기 음성**으로 읽습니다. 설정 패널에서 «음성 종류»를 «기기 음성»으로 바꿔 직접 고를 수도 있습니다. (기존 기기 음성 선택 로직: Enhanced/Premium/Natural·Google·Siri 우선, 장난감 음성 제외 — 그대로)
- **호주 발음(🇦🇺, «멜버른 행사» 카드)**: Kokoro·Piper 모두 **호주 음성이 없습니다**(확인함). 기기에 en-AU 음성이 있으면 그것을 쓰고, 없으면 영국 녹음 음성으로 대신 읽으며 카드에 그렇게 안내합니다(호주 억양은 아닙니다).
- 이 방식을 고른 이유(출처 확인한 사실만): 브라우저에서 모델을 직접 돌리는 방식(kokoro-js·Piper WASM)은 iPhone Safari에서 메모리 부족·WebGPU 문제 보고가 있고 모델이 q8 기준 86–92MB(fp32 325MB)라, 미리 만든 mp3를 `<audio>`로 재생하는 쪽이 iPhone에서 가장 안전하다고 판단했습니다. 재생은 사용자 탭 안에서 같은 `Audio` 요소로 동기 호출합니다(iOS 정책).
- 객관 점검: 만든 음원을 Whisper(small)로 받아 적어 원문과 비교한 단어 오류율(WER) 약 3.6% (샘플 45문장). 사람 귀 평가가 아니라 «알아들을 수 있는지»의 대리 지표입니다.
- 설정 패널(«발음 듣기·연습»): 읽기 속도(보통/천천히), 자동 재생, **음성 종류(고품질 녹음/기기 음성)**, **발음기호·주의 소리(켬/끔)**. 설정은 `english-flashcards-tts-v1`에 저장되며 예전 저장값(rate, autoplay)도 그대로 읽힙니다.

### 라이선스 · 출처

| 구성 | 라이선스 | 용도 |
|------|----------|------|
| Kokoro-82M v1.0 (hexgrad) · kokoro-onnx | Apache-2.0 | 영어 음원 생성 |
| eSpeak NG (phonemizer) | GPL-3.0-or-later | 발음기호 텍스트를 만드는 **빌드 도구**로만 사용(앱에는 코드가 들어가지 않고 결과 텍스트만 포함) |
| 음원(mp3) | 모델 출력물 | 이 저장소에서 자유롭게 사용 |

### 발음 코치 (발음기호 · 따라 말하기)

- **발음기호 + 헷갈리기 쉬운 소리**: 카드를 뒤집으면 각 문장 밑에 eSpeak NG(음소 변환 엔진)로 만든 IPA 발음기호가 나옵니다. 한국어 화자가 어려워하는 소리가 들어 있으면 짧은 요령 (th, f·v, r·l, z)이 나옵니다.
- **🎤 따라 말하기**: 버튼을 누르고 문장을 말하면 브라우저 음성인식(Web Speech API `SpeechRecognition`)이 받아 적고, 앱이 **단어별로 비교**해 점수·초록/주황/빨강 표시·«인식된 말»과 정답 단어의 발음기호를 보여 줍니다(OpenPronounce의 «기대 소리 vs 들린 소리» 아이디어를 가볍게 이식). 서버·API 키 없음. 음성인식이 안 되는 브라우저에서는 버튼이 숨겨지고 설정 패널에 안내가 뜹니다.
  - 한계: 음성인식은 문맥으로 말을 보정하므로 점수는 **참고용**(소리 자체의 정확도 평가가 아니라 «알아듣는지» 확인)입니다.
  - iPhone: Safari 14.5+ 에서 부분 지원(caniuse). **설정에서 Siri(받아쓰기)가 켜져 있어야** 하고, **홈 화면에 추가한 앱·SafariViewController 에서는 동작하지 않습니다**(WebKit 버그 #225298). 이 앱은 실제 iPhone에서 시험하지 못했습니다.

### 함께 고친 CSV 업로드 문제

- CSV 카드 id가 «행 번호»라 서로 다른 CSV를 올리면 학습 기록이 섞이던 문제 → 내용 해시 기반 id(같은 파일을 다시 올리면 같은 id라 기록 유지, 중복 행도 고유).
- 엑셀이 만든 **CP949(EUC-KR)** CSV 글자 깨짐 → UTF-8 엄격 검사 후 CP949로 자동 대체.
- **쉼표·세미콜론·탭** 구분자 자동 감지.

### 오디오 다시 만들기 (개발자)

`tools/` 에 생성 스크립트가 있습니다. 모델 파일은 저장소에 없습니다(`kokoro-v1.0.onnx`, `voices-v1.0.bin`: github.com/thewh1teagle/kokoro-onnx 릴리스).

```bash
pip install kokoro-onnx phonemizer espeakng-loader soundfile numpy   # + ffmpeg
node tools/dump_cards.js          # cards.js → english_cards.json
python tools/gen.py english            # audio/<해시>.mp3 생성 (이미 있으면 건너뜀)
python tools/build_data.py english     # audio/audio-data.js (음원 목록 + 발음기호) 생성
```

파일 이름은 `cyrb53("<음성>|<n 또는 s>|<문장>")` 의 16진수이고, 앱(`index.html`)이 같은 식으로 계산해 찾습니다. 문장이 바뀌면 해시가 달라져 자동으로 기기 음성으로 대체됩니다.

## 간격 반복 학습 (Anki 방식)

Anki의 학습 방식을 분석(공식 문서 + `ankitects/anki` 소스의 `review.rs`·`learning.rs`·`relearning.rs`·`fuzz.rs`·`steps.rs`)해 이식했습니다. 카드는 **신규 → 학습중 → 복습(21일 이상이면 성숙)** 으로 움직이고, 평가는 4단계입니다.

| 버튼 | 키 | 동작 |
|------|----|------|
| 다시 | 1 | 신규/학습중: 3장 뒤 재등장. 복습 카드: 실수(lapse) +1, 재학습으로 이동, 난이도(ease) −0.2, 새 간격 1일 |
| 어려움 | 2 | 신규/학습중: 6장 뒤 재확인(정답·오답 집계에는 넣지 않음). 복습: 간격 ×1.2, ease −0.15 |
| 좋음 | 3 (뒤집은 뒤 Space/Enter) | 신규: 1일 후 복습으로 졸업. 복습: (현재 간격 + 연체일/2) × ease |
| 쉬움 | 4 | 신규: 약 4일(퍼지 3–5일). 복습: (현재 간격 + 연체일) × ease × 1.3, ease +0.15 |

- 버튼마다 **다음 간격 미리보기**(예: `3장 뒤`, `1일`, `26일`, `1.2개월`)가 보입니다.
- Anki 소스 상수 그대로: 시작 ease 2.5, 최소 1.3, 어려움 배수 1.2, 쉬움 보너스 1.3, 간격 퍼지(2.5일 미만은 없음, 구간별 ±), 일찍 복습 시 별도 공식, 실수 8회째 **리치(leech)** 판정(이후 4회마다) → 자동 중지(설정에서 끌 수 있음).
- **상단 대시보드**: 연속 학습일, 오늘 학습 수, 복습 대기 수. **신규 / 학습중 / 복습** 카운트.
- **하루 한도**: 하루 신규 카드(5–40장, 기본 18) · 하루 복습 한도(30–500, 기본 100). 한도를 다 쓰면 «오늘 끝» 화면이 나오고 «신규 10장 더 학습»을 고를 수 있습니다.
- **되돌리기**: 마지막 평가를 취소(최대 30단계, Z 또는 Ctrl/Cmd+Z). 별표/중지도 되돌릴 수 있습니다.
- **별표(S) · 중지(P)**: 별표만 모아 학습, 중지한 카드는 세트에서 빠지고 통계 화면에서 다시 켤 수 있습니다.
- **통계 화면**: 오늘 학습·정답률·연속일, 최근 12주 **히트맵**, 카드 성숙도 분포(신규/학습/복습/성숙), 앞으로 7일 복습 예측, 중지 카드 목록.
- **백업/복원**: 모든 학습 기록을 JSON 파일로 내려받고(또는 복사), 같은 파일로 복원합니다. 브라우저 저장소(localStorage)에만 기록이 있으므로 주기적으로 백업하세요.
- **모바일(iPhone)**: 평가 버튼은 화면 아래에 고정되고, 설정은 접이식 «설정» 안으로 모았습니다.
- 키보드: Space/Enter 뒤집기(뒤집은 뒤엔 좋음) · 1–4 평가 · ←/→ 다시/좋음 · Z 되돌리기 · S 별표 · P 중지
- 평가 버튼을 **2단계(틀림/맞음)** 로 줄이는 설정, 7일 복습 켜기/끄기 설정도 있습니다.

### Anki 소스 그대로인 부분 / 이 앱에 맞춘 부분

- **그대로**: 복습 간격 공식, ease 증감, 퍼지 범위, 리치 기준, 성숙(21일) 정의.
- **이 앱의 변형**: 시간 단위의 학습 단계(1분/10분)는 «N장 뒤»로 바꿨습니다(세션 기반). 퍼지는 카드·날짜로 시드를 고정해 새로고침해도 같은 값입니다. 기존 **7일 주간 복습**은 SRS와 함께 유지됩니다(SRS 기한 전에 주간 복습으로 나오면 Anki의 «일찍 복습» 공식으로 계산). 이 앱은 FSRS가 아니라 SM-2 계열(Anki 기본 스케줄러)만 구현합니다.
- **기존 데이터 이관(이 앱의 자체 설계)**: 이전 버전 사용자는 `english-flashcards-srs-v1`이 없으면 기존 학습 기록과 주간 상태로 첫 SRS 상태를 만듭니다. 마지막 답이 틀렸으면 간격 1일, 맞았다면 연속 정답 1/2/3/4회 이상 → 1/3/7/14일. 기존 키(`session-v4`, `learn-log-v1`, `weekly-v1`, `custom-deck-v1`, `diff-overrides-v1`, `settings-v1`, `tts-v1`, `level-history-v1`)는 그대로 읽고 지우거나 덮어쓰지 않습니다. 새 키: `english-flashcards-srs-v1`, `english-flashcards-daylog-v1`, `english-flashcards-backup-meta-v1`.

## 오늘의 세트 · 주간 복습

- **오늘 세트**: 필터된 덱에서 **로컬 날짜 시드**로 섞어 하루치 카드를 뽑습니다. 같은 날·같은 필터면 같은 순서, 다음 날이면 다른 구성입니다. UI에 오늘 날짜와 «오늘의 세트»가 표시됩니다.
- **하루 신규 카드**: 기본 **18장** (5 / 10 / 12 / 15 / 18 / 20 / 25 / 30 / 40 선택 가능).
- **주간 복습**: 맞혀도 롤링 **7일** 안에 대략 **2번** 다시 나옵니다.
  - 첫 맞음 → 주 안에 한 번 더 복습 일정
  - 틀림 → 같은 세션 큐에 약 3장 뒤 재삽입 + 주간 노출에도 포함
- 스케줄은 브라우저 `localStorage`에 카드 id별로 저장됩니다. (키 접두사 `english-flashcards-` — 스페인어 앱과 겹치지 않음)

## 주간 레벨 보고 (CEFR 추정)

학습 기록(맞음·틀림, 난이도, 주제)을 `localStorage`에 쌓아 **달력 주(월–일)** 기준으로 추정 레벨을 보여 줍니다.

- UI: 접이식 패널 **«주간 레벨 보고»** (오늘의 세트 바로 아래)
- 표시: 추정 레벨(A1–C2), 근거(정답률·주로 푼 난이도), 학습 장수·정답률·난이도/주제 구성, 지난 주 추정(최대 8주)
- **보고서 복사** 버튼으로 한국어 요약을 클립보드에 복사
- **추정 · 학습 기록 기반**이며 공식 등급이 아닙니다. 공인 레벨은 IELTS·TOEFL·Cambridge 등 공인 시험이 필요합니다.

### 레벨 추정 방식 (휴리스틱)

1. 난이도 대역 → 기본 점수: 아주쉬움≈A2–B1(1.5), 쉬움≈B1(2), 어려움≈B2(3), 아주어려움≈C1(4)
2. 이번 주 정답률로 가감: 어려운 카드 고정확 → 상향, 쉬운 카드 저정확 → 하향
3. 학습량이 적으면 높은 등급을 과신하지 않도록 보정

## 사용 방법

1. **주제**를 고릅니다. (일상, 직장·비즈니스, 커피·카페, 여행, 음식, 감정, 문화, 시사, 관용구, 격식, 멜버른 행사 — 여러 개 선택 가능)  
   전체가 선택된 상태에서 하나를 누르면 그 주제만 선택됩니다. «전체»로 다시 모두 선택.
2. **난이도**를 고릅니다. (`전체` / `아주쉬움` / `쉬움` / `어려움` / `아주어려움`)
3. **학습 모드**
   - **기본 학습**: 한국어 → 영어(미국식 구어체 기준). 뒷면에 세 레지스터 모두 표시.
   - **혼합 재학습**: 앞면은 여전히 한국어. 카드마다 **미국식 구어체 / 격식체·문어체 / 영국식 구어체** 중 하나를 목표로 지정합니다.
4. **내 CSV 덱** (선택): 직접 만든 문장 CSV를 올려 공부할 수 있습니다.
5. «학습 시작»(진행 중에는 «다시 시작»)을 누르고, 카드를 **탭**해 뒤집으면 영어 답이 나옵니다. **다시 / 어려움 / 좋음 / 쉬움** 버튼(간격 미리보기 포함)은 뒤집힌 뒤에만 보입니다.
6. 답 화면에서 그 문장의 난이도를 바꿀 수 있습니다. 변경은 `localStorage`에 저장됩니다.

키보드 단축키는 위 «간격 반복 학습» 표를 참고하세요.
